ЗЕЛЁНЫЙ ДНЕВНИК — ОБНОВЛЕНИЕ ИНТЕРФЕЙСА И ИКОНОК

В архиве:
- index.html — обновлённый интерфейс и 32 варианта векторных иллюстраций комнатных растений; в выборе иконки отображаются только изображения без подписей.
- manifest.webmanifest — настройки устанавливаемого приложения.
- sw.js — service worker с новой версией кэша.
- icon-192.png, icon-512.png, icon-512-maskable.png — иконки ярлыка приложения.

УСТАНОВКА НА GITHUB PAGES
1. Распакуйте архив.
2. Загрузите все файлы в корень репозитория green-diary, заменив одноимённые файлы.
3. Нажмите Commit changes и подождите, пока GitHub Pages обновится.
4. На телефоне полностью закройте приложение и откройте снова. Новая версия service worker обновит кэш.

Существующие записи и история хранятся в локальном хранилище. Перед обновлением рекомендуется скачать JSON-резервную копию.
