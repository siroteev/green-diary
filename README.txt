ЗЕЛЁНЫЙ ДНЕВНИК — ОБНОВЛЕНИЕ ИКОНОК

В архиве:
- index.html — приложение с 24 новыми векторными иллюстрациями комнатных растений;
- manifest.webmanifest — настройки устанавливаемого приложения;
- sw.js — service worker с обновлённой версией кэша;
- icon-192.png, icon-512.png, icon-512-maskable.png — иконки ярлыка приложения.

УСТАНОВКА НА GITHUB PAGES
1. Распакуйте архив.
2. Загрузите файлы в корень репозитория green-diary, заменив одноимённые файлы.
3. Нажмите Commit changes и подождите, пока GitHub Pages обновится.
4. На телефоне полностью закройте приложение и откройте его снова. Если показывается старая версия, закройте вкладки сайта и запустите приложение повторно; при необходимости удалите кэш сайта в Chrome.

Иллюстрации комнатных растений встроены прямо в index.html — отдельную папку с иконками создавать не нужно.
Существующие записи хранятся в локальном хранилище. Новая версия преобразует старые emoji-иконки в ближайшие подходящие варианты и сохраняет историю растений.
Перед обновлением рекомендуется скачать JSON-резервную копию.
