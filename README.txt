ЗЕЛЁНЫЙ ДНЕВНИК — обновление PWA

Загрузите файлы из этого архива в корень репозитория green-diary на GitHub, заменив существующие index.html, manifest.webmanifest и sw.js. Добавьте в корень три файла иконок: icon-192.png, icon-512.png и icon-512-maskable.png. Папка icons больше не нужна для манифеста.

После Commit changes подождите 1–3 минуты. На телефоне закройте приложение и откройте сайт заново. Если отображается старая версия, полностью закройте Chrome/приложение и откройте ещё раз; новая версия Service Worker использует отдельный кеш.

Новые возможности:
• Иконка ярлыка — схематичный фикус эластика.
• Название приложения — «Зелёный дневник».
• Новый ориентир проверки по умолчанию: 7 дней с сентября по февраль и 5 дней с марта по август.
• Если грунт сухой раньше ориентира, приложение предлагает установить интервал по фактическому числу дней после полива.
• Если в двух последовательных циклах грунт остаётся влажным в день ориентира или позже, приложение предлагает увеличить интервал на 2 дня.
• Выбор из 24 вариантов иконок при добавлении и редактировании растения.

Данные существующих растений хранятся в локальном хранилище браузера; обновление файлов не должно удалять их. Перед крупными изменениями всё равно рекомендуется скачать резервную копию JSON.
