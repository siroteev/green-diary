Зелёный дневник — PWA для GitHub Pages

Загрузите ВСЕ файлы и папку icons в корень репозитория. Затем включите Settings → Pages → Deploy from a branch → main → /(root) → Save. Дождитесь публикации и откройте выданную HTTPS-ссылку на телефоне в Chrome.

После первой загрузки дождитесь окончания загрузки страницы, затем меню Chrome → Установить приложение (или Добавить на главный экран). Service worker кэширует приложение для офлайн-запуска.

Данные растений хранятся локально в браузере этого устройства (localStorage), не в GitHub. Не очищайте данные сайта; регулярно экспортируйте резервную копию.
